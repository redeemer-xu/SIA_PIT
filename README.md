# SIA_PIT - Electricity Billing System

**IT224 - Systems Integration and Architecture**  
**Final Performance Innovative Task**

## Project Overview
An integrated Electricity Billing System using Laravel REST API backend and Flutter mobile frontend.

## Project Structure
SIA_PIT/
├── backend/    # Laravel REST API (PHP)
└── frontend/   # Flutter Mobile App (Dart)

## Tech Stack
- **Backend:** Laravel 12, PHP 8.2, MySQL, Laravel Sanctum
- **Frontend:** Flutter (Dart), HTTP package
- **Database:** MySQL (XAMPP)

## Features
- ✅ Login Authentication (Admin & User)
- ✅ REST API Integration (10+ endpoints)
- ✅ View Bills
- ✅ Pay Bills
- ✅ Admin Dashboard
- ✅ Manage Users
- ✅ System Settings (rate per kWh)
